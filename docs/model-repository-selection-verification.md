# 远程模型与GitHub仓库发现验收

日期：2026-11-13（Asia/Shanghai）。

## 实现范围

仅工作台项目。新增OpenAI兼容模型列表、HTTP地址支持、GitHub身份后仓库选择、通用仓库与服务配置；Docker只输出架构分析，没有创建镜像或迁移运行环境。

## AI模型

- 显式获取baseUrl/models，Bearer Key仅随请求发送，模型列表只保留合法去重ID。
- 可搜索选择并原子保存Key/URL/model/models；修改URL或Key取消旧获取请求，迟到响应失效。
- 图片上传、视频分析、工坊实际使用当前会话model并记录该ID。
- 更改模型/Key会取消旧分析；无模型的旧会话需重新选择。
- HTTP/HTTPS/同源路径均允许；HTTPS浏览器到HTTP上游的限制以连接错误说明，不误报地址不合法。
- 本地HTTP测试服务实收GET /v1/models和POST /v1/chat/completions；选vision-beta后请求model确为vision-beta，Authorization匹配虚构测试Key，图片已附带。未向真实AI发送测试Key。

## 登录与仓库

- 无目标仓库也可GitHub OAuth/Token身份登录，随后自动读取仓库。
- 仓库搜索、默认分支、权限标识、分页加载、错误重试、归档只读。
- 目标权限与分支验证后才保存进入；旧仓库可显式继续，菜单可切换仓库。
- 切换数据仓库时清空依附旧目标的工作流/网站/视频连接；OAuth属于部署级连接。
- 作者的工作流与网站回退常量已移除。现有生产站点改成显式环境预设保持原站能力。
- GitHub真实只读验证：当前授权成功返回60个可访问仓库，包含既有数据仓库。
- 浏览器模拟身份流程：登录→列表搜索→选择release默认分支→验证进入；Token不写入仓库配置，390×700无文档溢出。

## 跨仓库保护

- 图片上传批次捕获仓库、分支与身份，每次底层写请求校验上下文；变化后中止，已传文件保留原库归属与元数据恢复状态。
- 图片去重/待元数据/AI缓存按owner/repo/branch隔离；旧无归属缓存不自动采用。
- 当前图片任务未完成时不能切换仓库，上传/元数据提交时不能切换页面或退出账号。
- 工作流请求按上下文和序号隔离，旧结果不能覆盖新仓库的状态、标签与统计。
