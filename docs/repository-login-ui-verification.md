# GitHub 登录与仓库发现界面验证

日期：2026-11-13。

最终交互按用户最新要求实现：GitHub 登录 → 自动发现可访问仓库 → 搜索选择 → 自动默认分支 → 验证并进入。首次登录不要求手填仓库。

- `LoginView.vue`：OAuth / Token 身份登录；已登录返回仓库选择，不静默跳入旧目标；明确“继续上次仓库”。
- `RepositoryPicker.vue`：首次自动请求、客户端搜索、加载更多、失败重试、空状态、请求取消；列表只存组件内存，退出清空。
- 仓库列表显示管理 / 可写 / 只读与公开 / 私有 / 归档状态。已归档仓库只读，并提示选择内容数据仓库。
- 选择后自动填入默认分支并允许修改；重新检查目标权限成功后才保存配置。只读账户需明确确认进入。
- 同一仓库保留依附服务，更换目标清除工作流 / 网站 / 视频服务连接；OAuth 安装配置保留。
- 未部署 OAuth 时可使用 Token；OAuth 连接可独立配置，不要求先填 owner / repo。高级手动配置仍复用 `RepositoryConfigForm.vue`。
- 页面固定 `100dvh`，内部表单与仓库列表滚动；沿用暗色 Apple 系统样式与现有过渡。

## 验证

`LoginView.test.js` 10 项、`RepositoryPicker.test.js` 3 项、`RepositoryConfigForm.test.js` 3 项，共 16 项通过。包括身份先行、默认分支、二次权限验证、无权限/网络失败不保存目标、只读确认、非法 redirect、旧配置不自动进入、跨仓库服务隔离、同仓库保留及归档只读。

限定 ESLint、`git diff --check` 与生产构建通过。构建仍有既有 chunk 大小与静态/动态混合导入提示。

没有提交、推送、部署或真实 GitHub 写操作。浏览器布局及完整 OAuth 流程由主代理统一验收。
