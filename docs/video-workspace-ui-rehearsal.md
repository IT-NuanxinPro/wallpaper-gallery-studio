# 视频工作台界面验证

日期：2026-11-13。

本次只重构真实 Studio 视频界面，借鉴 stageshow 的媒体缩略图优先、单次状态表达与动作反馈原则；视觉按用户后续要求改为暗色 Apple 系统质感。沿用 Vue / ElementPlus，不引入演示数据、React 或动效依赖。

## 交互落点

- `VideoJobQueue.vue` 提取队列职责：待办 / 已发布历史双页签、计数、分段状态筛选、真实候选帧缩略图、下一步提示。
- 默认待办排除已发布项；历史没有勾选框和批量发布；发布后状态变化即时移出当前待办与批量操作条。
- 审核区以视频预览、候选封面、发布信息为顺序。用途使用 ElementPlus 分段控件；主题使用可搜索、可输入新值的选择器。
- 已发布记录展示只读成果摘要，保留预览，移除表单、封面编辑和 AI 操作；可直接返回待办。
- 缺少 API Key 时 AI 禁用并链接共用设置，人工编辑仍然可用。失败任务可重试，暂停上传可继续。
- Apple 视觉第二版：页面标题为“视频工作台”，刷新采用圆形系统图标按钮；待办/历史采用玻璃胶囊分段，队列移除外层卡框；内容使用中性标准材质与 18–22px 圆角，扩大视频和候选帧。
- 窄屏单列、候选帧横向滚动，焦点可见，减少动态效果偏好下关闭过渡与平滑滚动。
- 发布完成提示只响应本页观察到的非 published → published 转换，初始加载历史不显示；用户关闭后轮询不重新出现。
